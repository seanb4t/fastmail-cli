# Acknowledgments

The JMAP client implementation in `internal/jmap/` is an original implementation built directly from the [JMAP specification (RFC 8620)](https://datatracker.ietf.org/doc/html/rfc8620) and the [JMAP Mail specification (RFC 8621)](https://datatracker.ietf.org/doc/html/rfc8621). The Masked Email and Sieve filter support follows Fastmail's [JMAP extension documentation](https://www.fastmail.com/dev/jmap).

The CardDAV and CalDAV protocol support is built on [Simon Ser's](https://github.com/emersion) excellent suite of Go WebDAV libraries.
